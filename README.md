Выбранная база данных предназначена для управления медицинскими данными пациентов и их взаимодействием с врачами.

В таблице "Patients" хранятся данные о пациентах, включая уникальный идентификатор (patient_id), имя (name), дату рождения (date_of_birth) и пол (gender).

Таблица "Doctors" содержит информацию о врачах, включая уникальный идентификатор (doctor_id) и имя (name).

Таблица "ChestPainTypes" описывает разные типы болей в груди, каждому из которых присвоен уникальный идентификатор (chest_pain_id) и описание боли (chest_pain).

В "ECGTypes" хранятся различные типы результатов ЭКГ, каждому из которых присвоен уникальный идентификатор (ecg_id) и описание результата (rest_ecg).

Таблица "PatientRecords" включает уникальный идентификатор записи (record_id), идентификатор пациента (patient_id), идентификатор врача (doctor_id), тип боли в груди (chest_pain_id), тип результатов ЭКГ (ecg_id), значение верхнего давления (rest_SPB), уровень холестерина (cholesterol) и максимальный пульс (max HR).

Эта база данных позволяет хранить медицинские записи пациентов, связывая их с соответствующими врачами и описывая различные параметры состояния пациентов, такие как боли в груди, результаты ЭКГ, а также параметры давления, холестерина и пульса. Это обеспечивает эффективное управление медицинской информацией и помогает врачам принимать информированные решения по лечению пациентов.
